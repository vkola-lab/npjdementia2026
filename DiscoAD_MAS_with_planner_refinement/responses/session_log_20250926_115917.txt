## 🧪 SCIENTIST – Analytical & Methodological Plans

### Option 1: Comparative Group Analysis (Cohort-Based)
- **Approach**: Stratify participants by treatment group (Rivastigmine vs. placebo or no intervention) and compare mean changes in *Memory* over time using repeated measures or longitudinal analysis.
- **Statistical Methods**: Linear mixed-effects models (LMMs) to account for within-subject variability and missing data; ANCOVA adjusting for baseline MMSE/MoCA scores and age.
- **Key Variables**: Memory (outcome), Cognitive_status_at_UDS_visit (exposure), Age, APOE genotype, number of E4 alleles.
- **Strengths**: Directly tests the hypothesis with causal inference potential if randomized.
- **Limitations**: Requires valid treatment assignment and time-series data (e.g., pre/post visit).

### Option 2: Multivariable Regression with Interaction Terms
- **Approach**: Use multivariate regression to assess whether Rivastigmine’s effect on memory differs based on key covariates such as APOE status, age, or AD diagnosis.
- **Statistical Methods**: Multiple linear regression with interaction terms (e.g., Rivastigmine × APOE_E4_count).
- **Variables of Interest**: Memory as outcome; treatment exposure (binary), APOE genotypes, age, MMSE, MoCA.
- **Insight Goal**: Identify subgroups where Rivastigmine shows stronger or weaker effects—potential biomarker interactions.
- **Advanced Step**: Include polynomial terms to model nonlinear relationships between age and memory change.

### Option 3: Sensitivity & Robustness Analysis
- **Approach**: Test how results hold under different assumptions (e.g., excluding outliers, imputing missing data, applying various definitions of "mild cognitive impairment").
- **Methods**: 
  - Exclude extreme memory values (>3 SD from mean).
  - Apply multiple imputation (e.g., MICE) for missing MMSE or MoCA scores.
  - Define "mild cognitive impairment" via thresholds (e.g., MoCA <25 or MMSE <27).
- **Purpose**: Ensure findings are stable across plausible data conditions.

### Option 4: Propensity Score Matching (PSM)
- **Approach**: Match treated (Rivastigmine) and untreated patients on baseline characteristics (age, cognition, APOE status) to reduce selection bias.
- **Variables Used**: Age, APOE genotype, MMSE score, MoCA, cognitive status at UDS.
- **Follow-up**: Compare memory outcomes post-treatment using paired t-tests or regression after matching.
- **Use Case**: When randomization is not feasible or treatment allocation was non-random.

### Option 5: Time-to-Event or Change-Scale Modeling
- **Approach**: Frame memory decline as a rate process—model how fast memory deteriorates in those receiving Rivastigmine versus controls.
- **Methods**: Cox proportional hazards models (for time to significant decline) or growth curve modeling (for continuous change trajectories).
- **Outcome**: Estimate hazard ratios or slope differences in memory trajectory.
- **Value**: More sensitive to early or delayed benefit than simple average comparisons.

        else:
            # Perform independent samples t-test on episodic memory (Memory score)

            # Conduct t-test assuming equal variances
            try:
                t_stat, p_val = stats.ttest_ind(mem_rivastigmine, mem_control, equal_var=True)

                except Exception as e:
                    print(f"T-test failed even with unequal variance: {e}")

    except KeyError as e:
