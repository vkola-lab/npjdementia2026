### 📐 Step 2: Primary Statistical Modeling – Adjusted Association Between Education and Dementia Risk  

**Objective**: Quantitatively test the core hypothesis using multiple models to establish both direction and strength of association.

#### Model Selection Pathway:

| Model Type | Purpose |
|---------|--------|
| **Logistic Regression** | Primary test of association between `EDUC` and `DEMENTED_YES` (binary outcome), adjusted for covariates |
| **Cox Proportional Hazards Regression** | Time-to-dementia analysis using `NACCAGE` as time variable, allowing evaluation of cumulative risk over lifespan |

**Model Specification**:

1. **Binary Outcome Model**:
   ```plaintext
   logit(P(DEMENTED_YES)) = β₀ + β₁(EDUC) + β₂(age) + β₃(sex) + β₄(race) + β₅(APOE e4) + β₆(MOCAscore) + ε
   ```
   - Include key confounders: `NACCAGE`, `SEX_FEMALE`, major racial groups (`RACE_WHITE`, `RACE_BLACKORAFRICANAMERICAN`, etc.), `APOE e4` status, and `NACCMOCA`.
   - Use **backward elimination** or **stepwise selection** to retain only significant predictors (p < 0.10 initially; final threshold p < 0.05).
   - Report **odds ratios (OR)** with 95% confidence intervals (CI) per 1-year increase in education.

2. **Time-to-Dementia Survival Model**:
   - Treat `NACCAGE` as time (start at baseline age), and define event as first occurrence of `DEMENTED_YES` or `NACCUDSD_DEMENTIA`.
   - Fit Cox model:
     ```plaintext
     hazard(t) = h₀(t) × exp(β₁·EDUC + β₂·age + ... )
     ```
   - Interpret **hazard ratios (HRs)** with 95% CI — HR < 1 indicates protective effect of education.
   - Test proportional hazards assumption via Schoenfeld residuals.

> 💡 Why not just correlation? Correlation does not control for confounding. These models isolate the independent contribution of education after accounting for known risk factors.

### 🔬 Step 3: Advanced Analyses – Mechanisms, Moderation, and Subgroup Effects  

**Objective**: Explore *how* education exerts its effect — through cognitive performance, gene-environment interaction, or population subtypes.

#### A. **Mediation Analysis** (Cognitive Reserve Pathway)  
Test whether improvement in cognitive function (`NACCMOCA`) mediates the relationship between education and dementia risk.

- Use **Baron & Kenny’s method** or structural equation modeling (SEM) to assess:
  - Does higher `EDUC` → better `NACCMOCA`?
  - Does better `NACCMOCA` → lower dementia risk?
- Calculate **indirect effects** and **mediation proportion** (e.g., % of total effect mediated by MOCA).
- Include interaction terms like `EDUC × APOE e4` to see if benefit diminishes in high-genetic-risk groups.

#### B. **Moderation Analysis**  
Test if the effect of education varies by:
- **Race/Ethnicity** (e.g., is the protective effect stronger in Whites than Blacks?)
- **Gender** (e.g., do women benefit more?)
- **APOE genotype** (e.g., does education offer less protection in those with two e4 alleles?)

- Fit interaction models:
  ```plaintext
  logit(DEMENTED_YES) = β₀ + β₁(EDUC) + β₂(GENDER×EDUC) + ...
  ```
- Conduct post-hoc subgroup analyses using chi-square tests or Wald tests.

> 🚩 **Critical Note**: Always report effect sizes (OR/Hazard Ratio) *with* 95% CIs across subgroups. Avoid pooling without checking homogeneity.

### 🔁 Step 4: Validation, Robustness, and Sensitivity Checks  

**Objective**: Confirm findings are reliable under different assumptions and analytical frameworks.

**Actions**:

| Strategy | Description |
|--------|-------------|
| **Cross-Validation** | Split data into training/validation sets (e.g., 70%/30%) and re-fit logistic/Cox models. Monitor consistency in estimated coefficients and predictive accuracy (e.g., AUC, calibration plots). |
| **Sensitivity Analysis** | Remove outliers (using IQR or Cook’s distance), exclude participants with incomplete MoCA, or restrict to older adults (>65). Compare results. |
| **Alternative Models** | Try polynomial regression (to capture non-linearity: e.g., quadratic term `EDUC²`) and compare fit statistics (AIC/BIC). Also consider **machine learning classifiers** (Random Forest, XGBoost) to validate the predictive power of education as a feature. |
| **Confidence Interval Width Check** | If CIs are wide (especially for low sample sizes in subgroups), discuss limitations and potential need for larger samples or meta-analysis. |

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
from scipy.stats import chi2_contingency, ttest_ind, f_oneway, pearsonr, spearmanr
import warnings
warnings.filterwarnings("ignore")

# Load the processed dataset
file_path = "./working/processed_dataset.csv"
try:
    df = pd.read_csv(file_path)
    print(f"Dataset loaded successfully. Shape: {df.shape}")
except FileNotFoundError:
    print("Error: Dataset not found at specified path.")
    exit()

# Display basic information about the dataset
print("\n--- Basic Dataset Information ---")
print(df.info())

print("\n--- Missing Values Summary ---")
missing_summary = df.isnull().sum()
missing_percentage = (missing_summary / len(df)) * 100
print(missing_summary[missing_summary > 0])
print("\nMissing value percentages:")
print(missing_percentage[missing_percentage > 0])

# Focus on key variables for hypothesis testing: EDUC and DEMENTED
# We'll filter out rows where either EDUC or DEMENTED is missing
filtered_data = df.dropna(subset=['EDUC', 'DEMENTED_NO', 'DEMENTED_YES'])

# Create binary outcome variable: DEMENTED (Yes/No)
filtered_data['DEMENTED'] = filtered_data['DEMENTED_YES'].astype(bool)

# Descriptive statistics for EDUC by dementia status
print("\n--- Descriptive Statistics by Dementia Status ---")
grouped_education = filtered_data.groupby('DEMENTED')['EDUC'].agg(['mean', 'std', 'count']).round(2)
print(grouped_education)

# Test for difference in mean years of education between those with and without dementia
# Perform independent samples t-test
demented_edu = filtered_data[filtered_data['DEMENTED']]['EDUC']
non_demented_edu = filtered_data[~filtered_data['DEMENTED']]['EDUC']

t_stat, p_value = ttest_ind(demented_edu, non_demented_edu, equal_var=False)

print(f"\n--- Independent Samples T-Test (Education vs. Dementia) ---")
print(f"T-statistic: {t_stat:.4f}")
print(f"P-value: {p_value:.4f}")

# Calculate effect size using Cohen's d
def cohens_d(group1, group2):
    diff = abs(np.mean(group1) - np.mean(group2))
    std_pooled = np.sqrt((np.var(group1) + np.var(group2)) / 2)
    return diff / std_pooled

effect_size = cohens_d(non_demented_edu, demented_edu)
print(f"Cohen's d (Effect Size): {effect_size:.3f}")

# Visualize the relationship
plt.figure(figsize=(10, 6))
sns.boxplot(x='DEMENTED', y='EDUC', data=filtered_data)
plt.title("Years of Education by Dementia Status")
plt.xlabel("Dementia Status (0 = No, 1 = Yes)")
plt.ylabel("Years of Education")
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Optional: Check correlation between EDUC and MoCA score (corrected for education)
if 'NACCMOCA' in filtered_data.columns:
    corr_coef, _ = pearsonr(filtered_data['EDUC'], filtered_data['NACCMOCA'])
    print(f"\nPearson Correlation between EDUC and NACCMOCA: {corr_coef:.3f}")
else:
    print("\nNACCMOCA not available in filtered data.")

# Final conclusion statement
if p_value < 0.05:
    print("\n✅ Hypothesis Supported: There is a statistically significant difference in years of education between individuals with and without dementia (p < 0.05).")
    print(f"The effect size (Cohen’s d = {effect_size:.3f}) indicates a moderate to large practical difference.")
else:
    print("\n❌ Hypothesis Not Supported: No statistically significant difference in education levels between dementia groups (p ≥ 0.05).")
