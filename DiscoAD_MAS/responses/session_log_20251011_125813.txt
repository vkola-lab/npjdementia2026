### 📐 **Step 2: Survival Analysis Using Cox Proportional Hazards Model – Testing Incidence Over Time**

**Objective:** Test whether higher age increases the hazard rate of dementia onset, accounting for time-to-event structure and covariates.

**Why survival?**  
Dementia is an event-based outcome occurring over time. The hypothesis speaks of "increased incidence," which implies risk over time — best modeled via survival analysis rather than simple correlation.

**Model Specification:**
```r
coxph(Surv(time_to_dementia, status) ~ age + sex + education + ethnicity + race + other_covariates,
     data = filtered_data, 
     robust = TRUE)
```

**Key Components:**
- Define **time-to-dementia** as the difference between `Year_of_death` (or latest follow-up) and `Subjects_age_at_visit`, **only for subjects who met dementia criteria**.  
  - For those without dementia, use censoring at end-of-follow-up or death (if applicable).
- Assign `status`: 1 = dementia event, 0 = censored (still alive or no diagnosis).
- Include **covariates**:
  - `Subjects_sex`, `Years_of_education`, `HispanicLatino_ethnicity`, racial indicators (as dummy variables), and possibly `Followup_status_at_the_Alzheimers_Disease_Center_ADC`.

**Assumptions Check:**
- Verify proportional hazards assumption using Schoenfeld residuals and log-log plots.
- If violated, consider time-dependent covariates or stratified models.

**Output Focus:**
- Hazard ratio (HR) per year increase in age (e.g., HR = 1.05 → 5% higher risk per additional year).
- 95% confidence intervals (CIs): interpret whether CI includes 1 (statistical significance).
- Adjusted p-values after controlling for known confounders.

> ⚠️ *Note:* Since all data is complete, we avoid imputation issues. But model assumptions must be validated rigorously.

> ✅ *Advantage*: Simpler interpretation than survival models, especially for policymakers or clinicians unfamiliar with survival concepts.

### 💡 **Step 4: Advanced Validation & Robustness Checks**

**Goal:** Ensure findings are stable, generalizable, and not driven by spurious patterns or model misspecifications.

**Strategies:**
1. **Cross-Validation (Time-Dependent Split)**  
   - Split the cohort into early (<1980) and later (>1990) waves of enrollment.  
   - Fit models separately and compare HR/OR stability across eras.  
   - Test for temporal trends in age-related risk — could indicate changing societal factors.

2. **Sensitivity Analysis**  
   - Recalculate results excluding very old individuals (>100 years) to check for influence of outlier cases.  
   - Exclude subjects with incomplete follow-up or missing death dates (even though total missing is zero, some may have unknown death timing).  

3. **Alternative Models Comparison**  
   - Compare results from linear regression (predicting probability of dementia as function of age) vs. logistic regression.  
   - Evaluate whether the relationship appears linear or nonlinear using polynomial terms (quadratic term in age):  
     ```r
     age_squared <- age^2
     ```
     Add to model to test for non-linearity (e.g., diminishing returns beyond certain age thresholds).

4. **Confounding Adjustment via Multivariable Modeling**  
   - Re-run models with adjustment for education, sex, and ethnicity — confirm that age remains independently significant.  
   - Perform backward elimination or stepwise selection to identify most predictive variables.

5. **Bayesian Inference (Optional Extension)**  
   - Use Bayesian hierarchical modeling to quantify uncertainty in HR/OR across subgroups and allow for shrinkage toward population-level estimates.

> 🛡️ *Purpose*: Prevent overfitting, detect data-driven noise, and strengthen credibility through multiple lines of evidence.

import pandas as pd
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt
import seaborn as sns

# Load the filtered dataset from the working directory
file_path = "./working/filtered_dataset.csv"
try:
    df = pd.read_csv(file_path)
    print(f"Dataset loaded successfully. Shape: {df.shape}")
except FileNotFoundError:
    print("Error: The file './working/filtered_dataset.csv' was not found.")
    exit()
except Exception as e:
    print(f"Error loading the dataset: {e}")
    exit()

# Display basic information about the dataframe
print("\n--- Basic Information ---")
print(df.info())

print("\n--- Summary Statistics (Numeric Columns) ---")
print(df.describe())

# Check for missing values
missing_values = df.isnull().sum()
print("\n--- Missing Values per Column ---")
print(missing_values[missing_values > 0])

# Focus on the key variables for the hypothesis: age and dementia status
print("\n--- Hypothesis Variables ---")
age_column = 'Subjects_age_at_visit'
dementia_column = 'Met_criteria_for_dementia'

# Verify presence of required columns
if age_column not in df.columns:
    print(f"Error: Column '{age_column}' not found in the dataset.")
    exit()
if dementia_column not in df.columns:
    print(f"Error: Column '{dementia_column}' not found in the dataset.")
    exit()

# Ensure we're analyzing only valid entries (no NaNs in age or dementia)
valid_data = df.dropna(subset=[age_column, dementia_column])
print(f"\nAfter removing NaNs in age and dementia: {len(valid_data)} rows remain.")

# Descriptive statistics for age by dementia status
print("\n--- Age Distribution by Dementia Status ---")
age_by_dementia = valid_data.groupby(dementia_column)[age_column].agg(['mean', 'std', 'count']).round(2)
print(age_by_dementia)

# Perform independent samples t-test to assess association between age and dementia incidence
# Null hypothesis: No difference in mean age between those with and without dementia
try:
    group1_mean = valid_data[valid_data[dementia_column] == 1][age_column].mean()
    group0_mean = valid_data[valid_data[dementia_column] == 0][age_column].mean()
    
    # Compute t-statistic and p-value
    t_stat, p_value = stats.ttest_ind(
        valid_data[valid_data[dementia_column] == 1][age_column],
        valid_data[valid_data[dementia_column] == 0][age_column],
        equal_var=False  # Use Welch's t-test since variances may differ
    )
    
    print(f"\n--- Independent Samples t-test Results ---")
    print(f"Mean age with dementia: {group1_mean:.2f} years")
    print(f"Mean age without dementia: {group0_mean:.2f} years")
    print(f"T-statistic: {t_stat:.4f}, P-value: {p_value:.4f}")
    
    # Effect size using Cohen's d
    def cohens_d(group1, group2):
        diff = abs(np.mean(group1) - np.mean(group2))
        std_pooled = np.sqrt((np.var(group1) + np.var(group2)) / 2)
        return diff / std_pooled
    
    effect_size = cohens_d(
        valid_data[valid_data[dementia_column] == 1][age_column],
        valid_data[valid_data[dementia_column] == 0][age_column]
    )
    print(f"Cohen's d (effect size): {effect_size:.3f}")
    
    # Interpretation
    if effect_size < 0.2:
        effect_interpretation = "Small"
    elif effect_size < 0.5:
        effect_interpretation = "Moderate"
    else:
        effect_interpretation = "Large"
        
    print(f"Effect Size Interpretation: {effect_interpretation}")

except Exception as e:
    print(f"Error during t-test: {e}")

# Optional: Visualize age distribution by dementia status
plt.figure(figsize=(10, 6))
sns.boxplot(data=valid_data, x=dementia_column, y=age_column)
plt.title("Age Distribution by Dementia Status")
plt.xlabel("Dementia Status (1 = Yes, 0 = No)")
plt.ylabel("Age at Visit (years)")
plt.grid(True, axis='y')
plt.tight_layout()
plt.show()

# Final conclusion statement
print("\n--- Scientific Conclusion ---")
if p_value < 0.05:
    print("The results support the hypothesis: higher age is significantly associated with increased dementia incidence.")
else:
    print("The results do not provide sufficient evidence to support the hypothesis that higher age is associated with increased dementia incidence.")
