### ✅ STEP 2: Survival Analysis – Time-to-Dementia Incidence Model  
*(Primary analysis for longitudinal risk prediction)*

#### Why?
Age is a known time-dependent risk factor, but dementia develops gradually. Survival models account for **time-to-event**, which is more biologically meaningful than cross-sectional odds ratios.

#### Methodology:
1. **Define Event Variable**:
   - Binary event: Dementia onset defined as `Met criteria for dementia_Yes == 1`.
   - Include `Cognitive status at UDS visit_Dementia` as a secondary proxy if no follow-up timeline exists (but prioritize the primary variable).

2. **Construct Cox Proportional Hazards Model**:
   ```plaintext
   Hazard = hazard_baseline × exp(β₁·age + β₂·hypertension + β₃·diabetes + β₄·APOE_e4 + ...)
   ```
   - Independent variables:
     - Age (`Subjects_age_at_visit`)
     - Hypertension (categorized: absent, active, remote)
     - Diabetes presence (Type I/II/other)
     - APOE e4 count (0, 1, 2 copies)
     - History of stroke or cardiac events
     - Heart valve procedure (within last 12 mo)

3. **Key Outputs**:
   - **HR (Hazard Ratio)** for age per year increase (with 95% CI)
   - **Statistical significance** (p-value)
   - **Proportional hazards assumption check** using Schoenfeld residuals and log-log plot
   - **Time-varying covariate consideration** if follow-up duration is tracked (if available)

4. **Model Diagnostics**:
   - Check collinearity using VIF (variance inflation factors) — especially between age and APOE/e4.
