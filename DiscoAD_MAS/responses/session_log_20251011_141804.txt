## ✅ Step 2: Primary Statistical Analysis – Survival Modeling Using Cox Proportional Hazards  
*Goal: Assess the strength and direction of age-related dementia incidence while properly handling time-to-event dynamics.*

**Why?**  
Dementia is a chronic condition that develops over time. The hypothesis involves "incidence" — i.e., the probability of developing dementia at a given age — which makes **survival analysis** more appropriate than simple cross-sectional association.

**Methodology**:  
- Construct a **time-to-dementia event** dataset where:  
  - Time = `Form_date_year - Subjects_age_at_visit` (or alternatively, `Form_date_year` if age-at-visit is fixed)  
  - Event = `Met_criteria_for_dementia == 1`  
  - Censoring occurs when subjects do not meet dementia criteria or are deceased without diagnosis (but only if death was not due to dementia).  

⚠️ *Critical consideration*: Only include individuals who have not yet developed dementia at baseline (i.e., `Met_criteria_for_dementia == 0`) to avoid reverse causality or misclassification.  

- Fit a **Cox proportional hazards model** with:  
  - Predictors: `Subjects_age_at_visit`, `Years_of_education`, `Subjects_sex`, and interaction terms (e.g., age × sex).  
  - Outcome: Time until first dementia diagnosis (or censoring).  

- Output:  
  - Hazard ratio (HR) per year increase in age.  
  - 95% confidence intervals (CIs) for HR.  
  - Goodness-of-fit checks (e.g., Schoenfeld residuals, log-log plot).  
  - Tests for proportionality assumption (via scaled Schoenfeld residuals).  

> 💡 *Flexibility note*: If the proportional hazards assumption fails, consider time-varying covariates or alternative models like accelerated failure time (AFT).

    alpha = 0.05
    if p_value < alpha:
        print(f"Hypothesis supported: There is a statistically significant difference in average age between dementia and non-dementia patients (p < {alpha}).")

    # Compute Cohen's d for effect size
    def cohens_d(group1, group2):
        diff = np.abs(group1.mean() - group2.mean())
        std_pooled = np.sqrt((group1.std()**2 + group2.std()**2) / 2)
        return diff / std_pooled
    
    cohens_d_val = cohens_d(age_with_dementia, age_without_dementia)
    print(f"Cohen's d (effect size): {cohens_d_val:.3f}")
