#### **Step 2: Test Association with a Logistic Regression (Null Hypothesis: β = 0)**

**Objective**: Test whether alcohol consumption is significantly associated with progression to dementia (i.e., is the odds ratio ≠ 1?).

**Null Hypothesis**:  
*The odds of progressing to dementia are the same for individuals who consume alcohol vs. those who don’t (OR = 1).*

**Alternative Hypothesis (directional)**:  
*Individuals who consume alcohol have higher odds of progressing to dementia (OR > 1).*

**Statistical Test**:  
- **Logistic regression** (simple binary regression) to estimate the **odds ratio (OR)** for `ALCOCCAS_YES`.
- Report:
  - **p-value** (to test if OR ≠ 1)
  - **95% confidence interval** for the OR
  - **Effect size** (OR and 95% CI)

> ✅ **Why logistic regression?**  
> - Ideal for binary outcome (dementia progression).  
> - Directly tests whether the coefficient is significantly different from 0 (i.e., null hypothesis).  
> - Produces interpretable effect size (OR) with direction.

**Code (simple, robust)**:
```python
from sklearn.linear_model import LogisticRegression
import statsmodels.api as sm

# Prepare features and target
X = df_filtered[['ALCOCCAS_YES']]
y = df_filtered['NACCIDEM_PROGRESSED_TO_DEMENTIA']

# Add intercept
X = sm.add_constant(X)

# Fit model
model = sm.LogisticRegression().fit(X, y)

# Summary output
results = model.summary()
print(results)

# Extract key values
coefficient = model.coef_[0][1]
p_value = model.pvalues[1]
ci_lower, ci_upper = model.conf_int()[1][1], model.conf_int()[1][1]
# Note: statsmodels provides the confidence intervals for coefficients, not OR directly
# So we compute OR = exp(coefficient)
or_val = np.exp(coefficient)
ci_or_low = np.exp(model.conf_int()[0][1])
ci_or_high = np.exp(model.conf_int()[1][1])

print(f"Odds Ratio (OR) for alcohol consumption: {or_val:.3f}")
print(f"95% CI: [{ci_or_low:.3f}, {ci_or_high:.3f}]")
print(f"P-value for OR ≠ 1: {p_value:.4f}")
```

> 🔍 **Interpretation**:
> - If **p < 0.05**, reject the null hypothesis → strong evidence that alcohol consumption is associated with increased dementia risk.
> - If **OR > 1**, it supports the hypothesis direction.
> - Always report **exact p-value**, not just "p < 0.05".
